Your song. Your visual world.

Create an effect in a plain JSON file. Layer shapes and particles, animate every numeric property, or write a fragment shader for a completely original visual. No rebuild or plugin installation is needed.

Start in a minute

  1. Play a song, open wallpaper settings with S, and find Custom song effects.
  2. Choose Download starter for current song. It already contains the song title and artist.
  3. Edit the downloaded JSON in a text editor. Change colors, add layers, or adjust the animation.
  4. Use Import effect file. Your effect activates for matching songs. Preview tries any saved effect on the current song, including a disabled entry.
  5. Edit and reimport to update it. Keep the same id to replace that entry; use a new ID to add another.

Lively blocks browser downloads. Download/Export opens the updated paired companion’s Windows Save As dialog. Choose a folder and filename, or Cancel without saving. The panel confirms the saved path; it does not show a JSON preview.

The paired companion saves the library and enable state in wallpaper-settings.json, with browser storage as an offline cache. Update the companion to enable this; without pairing, effects remain in this browser or Lively profile. Export your library to back it up or share it. Editing the original file takes effect after reimporting. Invalid imports keep the saved library and active effect.

A minimal effect

{
  "version": 1,
  "effects": [{
    "id": "my-neon-ring",
    "name": "My neon ring",
    "match": { "titles": ["My Song"], "artists": ["My Artist"] },
    "layers": [{
      "type": "ring",
      "color": "#b66dff",
      "size": { "value": 0.3, "audio": "bass", "amount": 0.08 },
      "thickness": 0.003,
      "opacity": 0.7
    }]
  }]
}

Files contain one or more effects. Each needs a unique id, a display name, a match, and exactly one of layers, shader or timeline. Set "enabled": false to store an effect without automatically activating it.

Choose when it plays

Both title and artist must match. Names ignore case, accents and punctuation, while keeping complete names: “My Artist Tribute” does not match “My Artist”. Add aliases to the titles and artists arrays. Any title plus any artist in those arrays qualifies. Complete artist credits in collaborations are supported; album artist is used only when artist is empty.

Common remaster, live, remix and other version suffixes are ignored by default. Set "versions": "exact" inside match to retain version text. Add "album": "Album name" there to restrict the release. The last matching library entry wins. Reimporting an ID moves it to the end.

Set "replace": false on an effect to overlay the genre atmosphere and built-in easter eggs. The default is false. Keep current atmosphere (overlay) is enabled in settings and also overlays older files; disable it to honor an explicit true replacement. The album-color gradient, TV and lyrics remain. Click the same Preview button again to stop it. Preview also ends on a recording change, on an import/library edit, or with Stop effect preview. The separate Enable custom effects toggle controls the library.

Build a composition

Layers draw in array order. All layers support position, scaling, rotation, color, opacity and blend mode. Coordinates use the whole wallpaper: x=0 is left, x=1 is right, y=0 is bottom, and y=1 is top. Sizes use viewport-height units with aspect correction, so circles stay circular on wide and narrow screens. Effects render behind the TV and lyrics.

Animate anything

Replace any numeric parameter above with an object. Combine keyframes, sinusoidal motion and an audio signal in the same parameter:

"size": {
  "value": 0.2,
  "keyframes": [[0, 0.2], [4, 0.35], [8, 0.2]],
  "loop": true,
  "period": 2,
  "amplitude": 0.02,
  "phase": 0,
  "audio": "bass",
  "amount": 0.1
}

Keyframes are [seconds, value] pairs starting at 0 with strictly increasing times. Values interpolate linearly and hold at the last frame unless loop is true. Keyframes replace the base value; without keyframes, omitted value uses the parameter default. Oscillation adds sin(2π × (time / period + phase)) × amplitude. Audio adds signal × amount (default amount 1). The final value is clamped to the parameter range.

Audio signals are bass, mid, treble, amplitude (weighted spectrum average), and onset (a transient measure, not a BPM estimate). Signals follow the wallpaper's reactivity setting. Live spectrum requires Lively's audio callback; the browser demo provides simulated input. Without audio, animation continues and reactive contributions settle to zero.

Time is elapsed effect animation time since activation or a recording change, scaled by Background animation intensity. It is not the player's playback position: seeking does not seek these keyframes. Background animation off and reduced motion freeze time and zero audio; reduced motion also follows your OS. Lively pause and hidden windows suspend rendering. TV standby fades custom effects out. Effects dim when lyrics are visible.

Write a completely custom shader

Replace layers with a shader string defining vec4 effect(vec2 uv). Return linear RGB and straight alpha. UV ranges from 0 to 1, bottom left to top right. You can define helper functions and use procedural noise, signed distance fields, fractals or any other WebGL-compatible fragment logic. SpicyBond supplies the shader entry point, tone mapping and display color conversion.

vec4 effect(vec2 uv) {
  vec2 p = (uv - 0.5) * vec2(uResolution.x / uResolution.y, 1.0);
  float radius = 0.25 + uBands.x * 0.08;
  float glow = exp(-abs(length(p) - radius) * 100.0);
  vec3 color = mix(uPrimary, uAccent, 0.5 + 0.5 * sin(uTime));
  return vec4(color, glow * 0.7);
}

In JSON, put this code in a string and encode line breaks as \n. Exported files already do that. The aurora example is ready to edit. Do not add main(), #version, or redeclare the supplied uniforms.

UniformMeaning
float uTimeElapsed effect animation seconds
float uProgress0–1 repeating cycle; set effect-level duration in animation seconds (default 12)
vec2 uResolutionDrawing buffer width and height in pixels
vec3 uBandsBass, mid, treble, multiplied by reactivity
float uAmplitude, uOnsetWeighted average and transient signal
vec3 uPrimary, uAccent, uThirdLinear album palette colors

Helpers PI and hash(float) are supplied. Brightness, transition opacity and lyric dimming are applied to the returned alpha. Custom shaders do not execute JavaScript or load external assets. Keep GPU work bounded: shader compilation catches syntax errors but cannot estimate the runtime cost of arbitrary shader code. Reduced motion freezes the supplied time and audio inputs; a shader should use those inputs for all animation.

Schedule several shaders in one file

Choose Download timed shader starter in settings for an example matched to the current song. Replace an effect’s layers or shader with timeline. Keep all shader definitions and their cues in the same JSON file:

"timeline": {
  "clock": "playback",
  "shaders": [
    { "id": "warm", "shader": "vec4 effect(vec2 uv){return vec4(uPrimary,0.5);}" },
    { "id": "cool", "shader": "vec4 effect(vec2 uv){return vec4(uAccent,0.5);}" }
  ],
  "cues": [
    { "begin": "00:00:00.000", "end": "00:00:10.000", "shader": "warm",
      "transition": { "duration": 2, "easing": "smooth" } },
    { "begin": "00:00:10.000", "end": "00:00:25.000", "shader": "cool",
      "transition": { "duration": 2, "easing": "smooth" } }
  ]
}

begin and end accept seconds (including decimals) or HH:MM:SS.mmm timestamps, similar to TTML timing. This is a JSON effect format, not TTML XML. Cue intervals include begin and exclude end. Arrange them in time order without overlaps; transparent gaps are allowed. Reuse any shader ID across multiple cues. Export normalizes timestamps to seconds. The timeline ends after its final cue and does not loop.

A cue’s transition begins at its begin. Adjacent cues blend the previous shader into the next over duration seconds. Each shader keeps its own local time while blending. At gaps and the end, the outgoing cue fades to transparent over its own transition duration; a cue after a gap fades in from transparent. Duration defaults to the smaller of 1 second or half the cue length; it must be between zero and half the cue length. Set zero for a cut. Easing is smooth (smoothstep) or linear. Colors and alpha blend together in linear premultiplied space, preserving brightness through a crossfade. This morphs between rendered images; animate geometry within your shader for a shape transformation.

The default clock: "playback" follows fresh matching companion snapshots, including pause, playback rate and forward/backward seeks. It works with lyrics disabled and does not use the lyric offset or Background animation intensity. When timing is unavailable, it falls back to elapsed active effect seconds. Preview always starts at zero with elapsed time. Choose clock: "elapsed" to use elapsed time explicitly. Recording changes and preview restarts reset the elapsed clock. Reduced motion and Background animation off freeze the clock and audio, and select the current cue without fading; Lively pause/hidden windows suspend rendering.

Timeline shaders receive the usual uniforms. uTime is seconds since that cue began; it continues for an outgoing cue while blending. uProgress is its local time divided by cue length, clamped to 1. uSongTime is the timeline clock in seconds. In ordinary single-shader effects, uSongTime equals elapsed animation time. Use these supplied values for animation so motion controls can freeze it.

A timeline supports 1–16 shader definitions and 1–256 cues. All shader IDs must be unique and every cue must reference one. Every shader compiles before saving, including definitions that no cue uses. Import/export, preview, matching and companion persistence work just as for other effects.

Validation and limits

Files and saved libraries are limited to 512 KiB, with up to 64 effects, 16 layers per effect, 512 combined particles per effect, 128 keyframes per parameter, and 32 title/artist aliases per match. Shader strings allow 32768 characters. Periods, duration and keyframe times go up to 86400 seconds. Oscillation phase, amplitude and audio amount range from −36000 to 36000. Unknown fields, out-of-range numbers and duplicate IDs in a file produce a field-specific error.

All imported shaders and generated layer programs compile on the current GPU before the library is saved. If any effect fails, the entire import is rejected. WebGL 2 is required. Performance presets and low power mode cap the shared renderer's pixel ratio and frame rate; use fewer layers and particles for lower GPU cost. At most two custom compositions exist during a crossfade.

For editor suggestions, save effect.schema.json next to your file and add "$schema": "./effect.schema.json" at the top. Runtime validation additionally checks parameter-specific ranges, keyframe ordering and total particle budgets.
